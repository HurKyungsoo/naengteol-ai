# Flaticon 재료 아이콘 다운로드 목록

스타일: **Special Flat** (작가: Magnific/Freepik) · 89개

## 받는 방법
1. 아래 링크를 열고 **PNG · 512px**로 다운로드한다. (로그인 필요, 무료 회원은 하루 다운로드 수 제한이 있다)
   - 링크의 아이콘을 모두 **컬렉션**에 담은 뒤 컬렉션을 한 번에 받는 방법도 있다. 무료 회원도 되는지는 받을 때 확인한다.
2. 받은 파일 이름을 **표의 "저장할 이름"**으로 바꿔 `assets/ingredients/flaticon-src/` 에 넣는다.
3. 다운로드할 때 나오는 **라이선스 문서(또는 출처 문구)**를 `assets/ingredients/flaticon-src/LICENSE.txt` 로 저장한다.
4. `node scripts/stylize-icons.mjs` 를 실행하면 3D 효과를 입힌 앱용 아이콘이 `assets/ingredients/` 에 만들어진다.

무료 라이선스는 **출처 표시가 필수**다 (앱의 마이 → 사진·아이콘 출처 화면에 표시).
