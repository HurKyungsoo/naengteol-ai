# 냉털AI 브랜드 · 아이콘

## 지금 앱에 쓰는 아이콘

- **입체형 (메인 시안), 기본형 다크그린**: 짙은 초록 바탕 + 크림색 냉장고 + 채소 그릇 + 반짝이.
- 원화: `assets/brand/app-icon-art.png`, 테마 아이콘(모노톤)용 `assets/brand/app-icon-mono-art.png`
- 앱 아이콘·안드로이드 적응형/테마 아이콘·스플래시·파비콘은 `python3 scripts/make-app-icon.py`로 만든다.
  그림 크기는 스크립트 위쪽 `ICON_WIDTH`(0.66), `ADAPTIVE_WIDTH`(0.42)로 조절한다.
- 색: 아이콘 바탕 `#06503D`(적응형 배경), 앱 안 포인트색은 그대로 주황 `#F26B2A`.

## 앱스토어 그래픽·홍보물에 참고할 시안

| 파일 | 내용 |
|---|---|
| `icon-variants.png` | 입체형 / 심플형 / 브랜드 심볼(N)형, 컬러 변형(다크그린·크림·라이트그린), 크기별 가독성 |
| `icon-styles.png` | 메인·심플·모노톤 버전, 배경색 조합(라이트·오렌지·다크), 크기 예시 |

- **컬러 변형** (스토어 그래픽, 홍보물 배경에 맞춰 고른다)
  - 기본형 (다크그린): 브랜드 색. 앱 아이콘으로 쓰는 것과 같은 색 조합
  - 라이트형 (크림): 밝은 배경 위에 놓을 때
  - 포인트형 (라이트그린): 신선하고 친근한 분위기가 필요할 때
- Android 런처 아이콘은 하나만 쓸 수 있어 앱에는 기본형만 들어간다.
- 시안 이미지는 해상도가 낮다(변형 하나에 200~300px). 실제 그래픽에 쓸 때는 원본을 큰 크기로 다시 받거나 다시 그린다.
